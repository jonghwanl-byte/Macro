# 📊 매크로 조기경보 (Macro Early Warning)

미국 채권·신용 시장의 핵심 지표 4가지를 매일 아침 텔레그램으로 받아보는 자동화 스크립트입니다.
단순 숫자가 아니라 **신호등 · 기준선 · 추세(1주/1달 변화) · 종합 위험도 점수**까지 함께 전송합니다.

---

## 📁 파일 구성

```
your-repo/
├── macro_alert.py                 # 메인 스크립트
├── requirements.txt               # 필요 패키지
├── README.md
└── .github/
    └── workflows/
        └── macro-alert.yml        # 매일 아침 자동 실행
```

> `macro-alert.yml`은 반드시 **`.github/workflows/`** 폴더 안에 넣어야 동작합니다.

---

## ⚙️ 설치 방법

### 1. FRED API 키 발급 (무료)
https://fredaccount.stlouisfed.org/apikeys 에서 가입 후 키 발급.

### 2. 텔레그램 봇 만들기
1. 텔레그램에서 `@BotFather` 검색 → `/newbot` → 봇 이름 지정 → **토큰** 획득
2. 만든 봇에게 아무 메시지나 전송
3. 브라우저에서 아래 주소 접속 → `chat.id` 값 확인
   ```
   https://api.telegram.org/bot<봇토큰>/getUpdates
   ```

### 3. GitHub Secrets 등록
저장소 → **Settings → Secrets and variables → Actions → New repository secret**

| 이름 | 값 |
|---|---|
| `TELEGRAM_TOKEN` | BotFather에서 받은 토큰 |
| `TELEGRAM_TO` | 위에서 확인한 chat id |
| `FRED_API_KEY` | FRED API 키 |

### 4. 테스트
저장소 **Actions 탭 → Macro Early Warning → Run workflow** 로 즉시 실행해 메시지가 오는지 확인하세요.

## ⏰ 실행 시각

`cron: '0 23 * * 0-4'` → UTC 23시 = **한국시간 월~금 오전 8시**

- 미국 증시 마감(한국시간 새벽 5~6시) 이후이므로 **전일 미국장 종가 기준** 데이터가 담깁니다.
- GitHub Actions 무료 러너는 혼잡 시 **5~30분 정도 지연**될 수 있습니다. 정시 도착이 필수가 아니라면 그대로 두어도 무방합니다.
- 시간 변경 예시: 한국시간 07:00 → `0 22 * * 0-4` / 한국시간 09:00 → `0 0 * * 1-5`

## 📈 지표 읽는 법

### 1. 하이일드 스프레드 (BAMLH0A0HYM2)
부실등급(정크) 회사채가 국채보다 얼마나 높은 금리를 줘야 하는지. **기업 부도 걱정의 온도계**.

| 값 | 상태 | 의미 |
|---|---|---|
| 3% 미만 | 🟢 안전 | 신용시장 안정. 단, 너무 낮으면 시장이 위험을 잊은 상태 |
| 3~4% | 🟡 보통 | 평균 수준 |
| 4~5% | 🟠 경계 | 신용 우려 확대. 주식 비중 점검 |
| 5% 이상 | 🔴 위험 | 신용경색. 과거 조정·침체 국면의 레벨 |

> **레벨보다 속도가 중요합니다.** 한 달 새 0.5%p 이상 급확대하면 절대값이 낮아도 경고로 처리합니다.

### 2. 장단기 금리차 10Y-2Y (T10Y2Y)
10년물 금리 − 2년물 금리. 마이너스면 **경기침체 예고등**.

| 값 | 상태 | 의미 |
|---|---|---|
| 0% 미만 | 🔴 역전 | 통상 12~18개월 뒤 침체와 연결 |
| 0~0.5% | 🟡 정상화 초기 | 역전 해소 직후. 과거 하락장이 이 구간에서 시작된 사례 다수 |
| 0.5~1.5% | 🟢 정상 | 무난한 우상향 곡선 |
| 1.5% 이상 | 🟡 가파른 정상화 | 금리인하 기대 또는 경기둔화 반영 |

> 역전을 겪은 뒤 한 달 새 0.25%p 이상 가팔라지는 **베어 스티프닝**이 가장 주의할 패턴입니다.

### 3. 단기자금 스트레스 (SOFR − IORB)
SOFR 숫자 자체는 그냥 정책금리를 따라갑니다. 의미 있는 건 **연준 지준부리(IORB)와의 격차**로, 벌어질수록 시중 돈이 마른다는 뜻입니다.

| 격차 | 상태 |
|---|---|
| 5bp 미만 | 🟢 원활 |
| 5~15bp | 🟡 약간 빡빡 (월말·분기말엔 흔함) |
| 15~25bp | 🟠 경색 조짐 |
| 25bp 이상 | 🔴 자금경색 (2019년 레포 발작급) |

### 4. MOVE 지수 (^MOVE)
채권판 공포지수(VIX의 채권 버전). **채권이 먼저 흔들리고 주식이 뒤따르는** 경우가 많습니다.

| 값 | 상태 |
|---|---|
| 80 미만 | 🟢 안정 |
| 80~100 | 🟡 보통 |
| 100~120 | 🟠 불안 (성장주·장기채 흔들림) |
| 120 이상 | 🔴 패닉 |

## 🎯 종합 위험도 (0~100)

4개 지표 점수를 합산합니다.

| 점수 | 판정 | 참고 대응 |
|---|---|---|
| 0~15 | 🟢 평온 | 위험자산 유지. 정기매수 계획대로 |
| 16~35 | 🟡 관찰 | 추세 점검. 신규 레버리지 자제 |
| 36~55 | 🟠 경계 | 현금 비중 확대 검토 |
| 56~75 | 🔴 위험 | 방어 전환. 주식 비중 축소·헤지 점검 |
| 76~100 | 🚨 비상 | 복수 지표 동시 악화. 자본 보존 우선 |

## 🛠 커스터마이징

- **기준선 조정**: `macro_alert.py`의 `judge_*` 함수 안 숫자를 바꾸면 됩니다.
- **지표 추가**: `get_fred_series("시리즈ID")` 형태로 FRED 지표를 얼마든지 추가할 수 있습니다. (예: `T10Y3M` 10년-3개월 금리차, `DTWEXBGS` 달러지수)
- **위험할 때만 받기**: `main()` 마지막에 `if total < 30: return` 을 넣으면 평온한 날은 알림이 오지 않습니다.

## ❗ 주의사항

- **시차가 있는 지표입니다.** 금리차 역전 후 실제 하락까지 12~18개월이 걸렸고, 그 사이 시장이 더 오른 사례도 많습니다. 신호 하나로 전량 매매하기보다 비중을 단계적으로 조절하는 용도로 쓰는 편이 낫습니다.
- FRED 지표는 미국 공휴일에 갱신되지 않아 전일과 같은 값이 나올 수 있습니다.
- 이 저장소는 공개 데이터를 요약해 보여줄 뿐이며 **투자 자문이 아닙니다.** 투자 판단과 결과의 책임은 전적으로 본인에게 있습니다.
