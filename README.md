# 📊 매크로 조기경보 (Macro Early Warning)

미국 채권·신용 시장 지표를 매일 아침 텔레그램으로 받아보는 자동화 스크립트입니다.
단순 숫자가 아니라 **신호등 · 기준선 · 추세(1주/1달/3개월) · 대응 가이드**까지 함께 전송합니다.

두 축을 나란히 보여줍니다.

| 축 | 보는 것 | 성격 |
|---|---|---|
| **① 신용·자금 스트레스** (0~100점) | 이미 문제가 터지고 있는가 | 상대적으로 후행 |
| **② 금리 레짐 (Rate Gravity)** | 금리 환경이 구조적으로 바뀌는가 | 상대적으로 선행 |

> 두 축은 **합산하지 않습니다.** 하이일드(HY)와 IG 회사채 스프레드는 상관이 매우 높아
> 한 점수에 넣으면 신용위험이 이중 계상되기 때문입니다.

## 📁 파일 구성

```
your-repo/
├── macro_alert.py                 # 전부 여기 (단일 파일)
├── requirements.txt
├── README.md
└── .github/
    └── workflows/
        ├── macro-alert.yml        # 매일 아침 실행
        └── keepalive.yml          # 스케줄 자동 비활성화 방지
```

> 워크플로우 파일은 반드시 **`.github/workflows/`** 안에 있어야 동작합니다.

## ⚙️ 설치

### 1. FRED API 키 (무료)
https://fredaccount.stlouisfed.org/apikeys 에서 발급.

### 2. 텔레그램 봇
1. 텔레그램에서 `@BotFather` → `/newbot` → **토큰** 획득
2. 만든 봇에게 아무 메시지나 전송
3. 아래 주소 접속해 `chat.id` 확인
   ```
   https://api.telegram.org/bot<봇토큰>/getUpdates
   ```

### 3. GitHub Secrets
저장소 → **Settings → Secrets and variables → Actions → New repository secret**

| 이름 | 값 |
|---|---|
| `TELEGRAM_TOKEN` | BotFather 토큰 |
| `TELEGRAM_TO` | chat id |
| `FRED_API_KEY` | FRED API 키 |

토큰이 들어가므로 **저장소는 비공개(private)** 로 두세요.

### 4. 테스트
**Actions 탭 → Macro Early Warning → Run workflow** 로 즉시 실행해 메시지 도착을 확인합니다.

## ⏰ 실행 시각

`cron: '0 23 * * 0-4'` → UTC 23시 = **한국시간 월~금 오전 8시**

- 미국 증시 마감(한국시간 새벽 5~6시) 이후라 **전일 미국장 종가 기준** 데이터가 담깁니다.
- GitHub Actions 무료 러너는 혼잡 시 **5~30분 지연**이 흔합니다. 정시가 중요하면 30분 앞당겨 두세요.
- 변경: KST에서 9시간을 빼서 UTC로 넣습니다. (07시 → `0 22 * * 0-4` / 09시 → `0 0 * * 1-5`)

### keepalive가 필요한 이유
GitHub 공식 문서는 "**공개** 저장소에서 60일간 활동이 없으면 스케줄 워크플로우가 자동 비활성화된다"고 명시합니다. 비공개 저장소는 그 문장에 포함되지 않지만, 비공개에서도 꺼졌다는 사례 보고가 있어 의견이 갈립니다.
비활성화되면 **에러도 배너도 뜨지 않고 조용히 멈추므로**, 월 1분도 안 되는 비용의 `keepalive.yml`을 넣어두는 편이 안전합니다.

## 📈 지표 읽는 법

### ① 신용·자금 스트레스 (0~100점)

#### 1. 하이일드 스프레드 (`BAMLH0A0HYM2`)
부실등급 회사채가 국채보다 얼마나 더 얹어줘야 하는지. **기업 부도 걱정의 온도계.**

| 값 | 상태 | 의미 |
|---|---|---|
| 3% 미만 | 🟢 안전 | 신용시장 안정. 단, 너무 낮으면 시장이 위험을 잊은 상태 |
| 3~4% | 🟡 보통 | 평균 수준 |
| 4~5% | 🟠 경계 | 신용 우려 확대. 주식 비중 점검 |
| 5% 이상 | 🔴 위험 | 신용경색. 과거 조정·침체 국면의 레벨 |

> **레벨보다 속도.** 한 달 새 0.5%p 이상 급확대하면 절대값이 낮아도 가산 경고합니다.

#### 2. 장단기 금리차 10Y-2Y (`T10Y2Y`)
10년물 − 2년물. 마이너스면 **경기침체 예고등.**

| 값 | 상태 |
|---|---|
| 0% 미만 | 🔴 역전 — 통상 12~18개월 뒤 침체와 연결 |
| 0~0.5% | 🟡 정상화 초기 — 과거 하락장이 이 구간에서 시작된 사례 다수 |
| 0.5~1.5% | 🟢 정상 |
| 1.5% 이상 | 🟡 가파른 정상화 — 인하 기대 또는 경기둔화 반영 |

> 역전을 겪은 뒤 한 달 새 0.25%p 이상 가팔라지는 **베어 스티프닝**이 최우선 주의 패턴입니다.

#### 3. 단기자금 스트레스 (`SOFR` − `IORB`)
SOFR 숫자 자체는 정책금리를 따라갈 뿐입니다. 의미 있는 건 **연준 지준부리와의 격차**로, 벌어질수록 시중 돈이 마른다는 뜻입니다.

| 격차 | 상태 |
|---|---|
| 5bp 미만 | 🟢 원활 |
| 5~15bp | 🟡 약간 빡빡 (월말·분기말엔 흔함) |
| 15~25bp | 🟠 경색 조짐 |
| 25bp 이상 | 🔴 자금경색 (2019년 레포 발작급) |

#### 4. MOVE 지수 (`^MOVE`)
채권판 공포지수. **채권이 먼저 흔들리고 주식이 뒤따르는** 경우가 많습니다.

| 값 | 상태 |
|---|---|
| 80 미만 | 🟢 안정 |
| 80~100 | 🟡 보통 |
| 100~120 | 🟠 불안 (성장주·장기채 흔들림) |
| 120 이상 | 🔴 패닉 |

#### 종합 점수

| 점수 | 판정 | 참고 대응 |
|---|---|---|
| 0~15 | 🟢 평온 | 위험자산 유지. 정기매수 계획대로 |
| 16~35 | 🟡 관찰 | 추세 점검. 신규 레버리지 자제 |
| 36~55 | 🟠 경계 | 현금 비중 확대 검토 |
| 56~75 | 🔴 위험 | 방어 전환. 주식 비중 축소·헤지 점검 |
| 76~100 | 🚨 비상 | 복수 지표 동시 악화. 자본 보존 우선 |

### ② 금리 레짐 (Rate Gravity)

**핵심 논리:** 금리 상승 자체가 위험한 게 아니라, *시장이 경험하지 못한 영역으로 돌이킬 수 없이* 올라가는지가 관건. 그 지점을 넘으면 AI 투자에 돈을 대던 자본 공급자(은행/VC/PE/연기금/채권투자자)가 이탈할 수 있다는 관점입니다.
따라서 모든 판정은 **순간 돌파가 아니라 추세적 돌파**로 합니다.

#### 미 10년물 (`DGS10`)

| 값 | 상태 | 근거 |
|---|---|---|
| 4.90 미만 | 🟢 정상 | 금리 상승만으로는 매도 근거 아님 |
| 4.90 이상 | 🟡 관찰 | 임계점 접근. 아직 경험했던 영역 |
| 5.00 추세 돌파 | 🟠 경고 | 5% 위에 머문 건 2007년이 마지막 |
| 5.30 추세 돌파 | 🔴 위험 | 5.3% 위에 머문 건 2000년이 마지막 |

> **추세 돌파 = 최근 20영업일 중 60% 이상이 임계값 위 + 최신값도 위.**
> 국채 입찰 직후 스파이크로 오탐이 나는 걸 막습니다.
> 레벨과 별개로 **3개월 상승폭 0.5%p 이상**이면 관찰로 올립니다.

#### 인플레이션 (`CORESTICKM159SFRBATL` + 주거비 제외 근원)

| 조건 | 상태 |
|---|---|
| 둘 다 미달 | 🟢 일회성 요인 범위 |
| 하나 돌파 | 🟠 경고 |
| 둘 다 돌파 | 🔴 Fed 인상 위험 구간 |

임계값: sticky CPI 3.5% / 주거비 제외 근원 3.0%
월간 지표라 값이 한 달 내내 같으므로 **기준월을 함께 표기**하고, 새로 갱신된 달에만 `★신규`가 붙습니다.

#### IG 회사채 OAS (`BAMLC0A0CM`) — 참고 항목
자본 공급자가 실제로 돌아서는지는 회사채 조달 여건에서 먼저 드러납니다. **3개월 저점 대비 확대폭**으로 봅니다. (25bp 이상 악화 조짐 / 50bp 이상 이탈 진행)
하이일드와 상관이 높아 **레벨 산정에서는 제외**하고 표시만 합니다.

#### 금리 하락 4조건 — 수동 입력
바클레이스 기준. 자동 판정이 어려워 `macro_alert.py` 상단 `RELIEF_FLAGS`에서 직접 관리합니다.

```python
RELIEF_FLAGS = {
    "경기지표 지속 약화": False,
    "미국 재정적자 억제": False,
    "AI 관련 회사채 발행 둔화": False,
    "재무부 장기채 공급 조절": False,
}
```

3개 이상 충족되면 "금리 하락 경로 열림"으로 표시됩니다.

#### 레벨별 대응

| 레벨 | 대응 |
|---|---|
| 🟢 정상 | 유지. 정기 리밸런싱 외 조정 없음 |
| 🟡 관찰 | 신규 납입분만 단기채 비중 상향. 기존 보유분 매도 없음 |
| 🟠 경고 | 주식 → 초단기채 10~15%p 이동 (목표 이동분의 절반) |
| 🔴 위험 | 잔여 10~15%p 추가 이동. AI 인프라/리츠 우선 축소 |

**한 번에 옮기지 않고 절반씩 나눠 실행**하는 게 핵심입니다. 신호가 되돌려질 때 손실을 줄입니다.

## 🛠 커스터마이징

모든 설정은 `macro_alert.py` 상단 **"설정" 블록**에 모여 있습니다.

- **기준선 조정**: `UST10Y_WARNING` 등 상수만 수정
- **지표 추가**: `SERIES` 딕셔너리에 FRED ID 추가 → `judge_*` 함수 하나 작성 → 메시지 조립부에 한 줄
  (예: `T10Y3M` 10년-3개월 금리차, `DTWEXBGS` 달러지수)
- **이벤트 캘린더**: `EVENT_WATCHLIST`에 `(date(...), "설명")` 추가. 지난 날짜는 자동 제외되고 3주 이내만 표시됩니다.
- **위험할 때만 받기**: `main()`의 메시지 조립 직전에
  ```python
  if total < 30 and g_level == Level.OK:
      print("특이사항 없음 - 전송 생략"); return
  ```

## ❗ 주의사항

- **시차가 있는 지표입니다.** 금리차 역전 후 실제 하락까지 12~18개월이 걸렸고, 그 사이 시장이 더 오른 사례도 많습니다. 신호 하나로 전량 매매하기보다 비중을 단계적으로 조절하는 용도로 쓰는 편이 낫습니다.
- **금리 레짐 임계값(5.00 / 5.30)은 검증된 수치가 아닙니다.** 특정 애널리스트가 한 시점에 제시한 견해이고 근거 사례는 2000년·2007년 두 번뿐입니다. 표본 2개는 통계적 검증이라기보다 서술에 가깝습니다. 자동 트리거가 아닌 참고 신호로 다루세요.
- **`CUSR0000SA0L12E`는 미검증 대용 시리즈입니다.** 기사가 말한 "주거비 제외 근원물가"와 정확히 같은 개념인지 FRED에서 시리즈 설명을 한 번 확인하시고, 다르면 `CPILFESL`(근원)과 주거비 시리즈로 직접 산출하세요. 지수 레벨 시리즈이므로 코드에서 `yoy_from_index()`로 전년비를 계산합니다.
- FRED 지표는 미국 공휴일에 갱신되지 않아 전일과 같은 값이 나올 수 있습니다.
- 이 저장소는 공개 데이터를 요약해 보여줄 뿐이며 **투자 자문이 아닙니다.** 투자 판단과 결과의 책임은 전적으로 본인에게 있습니다.
